========================================================================
             [갓생살기] 집 노트북에서 실행하는 초간단 가이드
========================================================================

■ 준비물 (무료)
1. Node.js (필수)
   - 웹사이트: https://nodejs.org
   - [LTS 버전] 다운로드 후 기본 옵션대로 'Next' 눌러서 설치.

2. VS Code (선택/권장)
   - 코드 수정 시 Visual Studio Code(https://code.visualstudio.com) 권장.

------------------------------------------------------------------------
■ 실행 방법 (더블클릭 방식)

1. 이 압축 파일의 압축을 집 노트북의 원하는 폴더(예: 바탕화면)에 풉니다.

2. [처음 한 번만]:
   - '1_처음_실행하기(설치포함).bat' 파일을 더블클릭합니다.
   - 자동으로 필요한 패키지를 설치하고 개발 서버가 시작됩니다.

3. [이후 평소에 실행할 때]:
   - '2_서버_실행하기.bat' 파일을 더블클릭하시면 바로 서버가 켜집니다.

4. 크롬이나 엣지 브라우저를 열고 주소창에 입력:
   http://localhost:3000

------------------------------------------------------------------------
■ VS Code 터미널에서 직접 실행하는 법 (개발자 방식)

1. VS Code로 이 폴더를 엽니다.
2. 상단 메뉴 [터미널] -> [새 터미널] 클릭
3. 터미널 창에 입력:
   npm install      (처음 1회만)
   npm run dev      (서버 실행)
4. http://localhost:3000 접속

------------------------------------------------------------------------
■ 스마트폰 모바일 테스트 (같은 Wi-Fi 사용 시)
- 집 노트북의 로컬 IP(예: 192.168.0.x:3000)를 스마트폰 브라우저에 입력하면
  스마트폰에서도 바로 접속하여 모바일 화면으로 테스트 가능합니다.
